# QuickNotes Service

QuickNotes is a high-performance note-taking web application designed to scale to 1,000,000 active users. 

## Project Structure
- `index.html`: Front-end user interface.
- `api.js`: Client-side application logic handling GET, POST, and DELETE requests.
- `style.css`: Clean, responsive styling.
- `docs/api-design.md`: REST API specification.
- `docs/data-model.md`: Database schema and entity design.
- `docs/architecture.md`: System architecture and scaling strategy.

## Getting Started
Open `index.html` in any modern browser or serve via a local static file server to test the API client.
