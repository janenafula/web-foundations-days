# QuickNotes App

QuickNotes App is a lightweight, responsive web application designed to help users quickly capture, organize, and manage daily thoughts and tasks. Users can categorize notes into Personal, Work, or Ideas sections, perform real-time text searches across their collection, and rest assured that their data persists safely across browser refreshes.

## Features

- **Add Notes:** Create notes categorized under Personal, Work, or Ideas.
- **Form Validation:** Prevents submission of empty notes or text exceeding 200 characters.
- **Delete Notes:** Remove individual notes easily.
- **Real-Time Search:** Instantly filter notes as you type in the search bar.
- **Data Persistence:** Automatically saves and retrieves notes using `localStorage`.
- **Dynamic Count:** Displays correct singular/plural note counts based on active display filter.
- **Responsive Design:** Optimized layout for mobile devices using Flexbox and CSS Media Queries.
